What is HTML?

HTML stands for hyperText markup language. It organizes web content such as headings, paragraphs, links, images, and forms. HTML provides structure, CSS controls looks, and JavaScript adds the interactive stuff.

Structure

HTML organizes the content of a web page.

Connections

Hyperlinks connect pages and resources across the web.

Standards

HTML standards help browsers interpret web pages.

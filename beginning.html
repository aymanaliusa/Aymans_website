The Beginning of HTML

How HTML started the web.

Tim Berners Lee

Tim Berners Lee made the starting versions of the Web we use today while working at CERN. In 1990, he created HTML to organize documents and connect them through hyperlinks.

Why HTML Matters

  • It organizes information into web pages.
  • It connects documents using hyperlinks.
  • It helps browsers display structured content.

Main learning point

HTML made sharing and navigating information on the web possible.
